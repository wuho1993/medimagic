Supabase CLI Workflow
---------------------
- Migration files in supabase/migrations now use unique 14-digit timestamps, for example 20260414200000_add_sales_bonus_custom_name.sql.
- Legacy file _seed_commission_tiers.sql was moved to supabase/archive because Supabase CLI ignores non-timestamped migration filenames.
- Remote migration history has been repaired to match the timestamped filenames, so `supabase db push --db-url <pooler-url>` works again.
- Preferred remote CLI pattern in this environment:
	1. Create new migration with a unique timestamp prefix.
	2. Use the session pooler connection string.
	3. Run `supabase db push --db-url "postgresql://postgres.<project-ref>:<password>@aws-1-ap-southeast-1.pooler.supabase.com:5432/postgres"`.
